# framebit.org

## Developing

### Installation

```
apt install hugo npm
npm install postcss-cli
```

### Start the Server

```
hugo server
```

### Creating New Content

```
hugo new content/whatever-dir/name-of-file.md -k <archetype>
```

```
hugo new content/snippets/looking-at-the-hills.md -k quote
```
